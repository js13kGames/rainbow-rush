# 🦄 Rainbow Rush 🦄

Rainbow Rush is an endless action game about a flying unicorn caught in a storm of shape-matched nightmares. Draw rainbow routes, rush through enemies and projectiles, chain combos, and beat your best score.

## Controls

Controls differ between desktop and mobile.

### Desktop

| Control | Action |
| --- | --- |
| Mouse | Move the unicorn |
| Click, drag, and release | Draw a path and rush along it |
| P | Pause or resume |
| M | Mute or unmute |

### Mobile

| Control | Action |
| --- | --- |
| Drag the unicorn | Move the unicorn |
| Drag through empty space and release | Draw a path and rush along it |
