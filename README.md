# Rainbow Rush

2026 js13kGames entry for the theme **Unicorns and Rainbows**, playable with mouse or touch in a landscape browser.

## Commands

- `pnpm install --frozen-lockfile` — install the pinned build dependencies
- `pnpm dev` — start the local development server at http://127.0.0.1:3000
- `pnpm lint` — check TypeScript and JavaScript with Oxlint
- `pnpm lint:fix` — automatically fix supported lint errors
- `pnpm build` — type-check and build `dist/index.html`
- `pnpm test` — run route-recognition geometry tests
- `pnpm zip` — build, minify, and create `release/rainbow-rush.zip`
- `pnpm size` — print exact archive bytes and remaining budget
- `pnpm check-size` — fail when the ZIP exceeds 13,312 bytes
- `pnpm verify` — test ZIP integrity, layout, extraction, and size

Rules and accepted design live in `docs/`.
